Deploy to GitHub Pages in 60 Seconds

This portfolio is a single, self-contained file (`index.html`) optimized for zero-configuration hosting on GitHub Pages.

Step 1: Open or Create your GitHub Pages Repo

Go to your GitHub account and use your existing repo ncsearth.github.io (or create ScripterNor12.github.io).

Step 2: Save as `index.html`

Save this complete HTML file into the root of that repository as index.html.

Step 3: Enable Pages

In the repo settings under Settings → Pages, select Deploy from a branch (Branch: main / root). Your live portfolio will be online at https://ncsearth.github.io or https://ScripterNor12.github.io!
